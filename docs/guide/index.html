Script Notifications

A running script can fire its own TaskTick notification at any point: print a sentinel line to stdout and TaskTick turns it into a native banner. The line itself is stripped from the output, so it never shows up in logs or the live view.

Syntax

Print a line that starts with @tasktick:notify (leading whitespace is allowed), followed by a single JSON object. "title" is required; "body" is optional; unknown keys are ignored.

@tasktick:notify {"title":"Update found","body":"Downloading v5.5.2"}

Example

#!/bin/bash
echo '@tasktick:notify {"title":"Backup started"}'
# ... do the work ...
echo '@tasktick:notify {"title":"Backup done","body":"42 files"}'

Notes

  • The directive line is removed from stdout — it won't appear in logs, the live view, or the tee file.
  • Only stdout is scanned, never stderr.
  • Honors the global notification toggle; at most 20 directive notifications per run.
  • Independent of the task's success/failure notifications — turn those off in the editor if you want to avoid duplicates.
