# TaskTick website

The official website is generated by **Hugo 0.168.0** and deployed to
<https://iuxt.github.io/TaskTick/> with GitHub Actions. No theme, Node.js,
third-party font CDN, or JavaScript framework is needed.

## Preview and build

From the repository root, install Hugo (`brew install hugo` on macOS), then run:

```sh
hugo server --source website
```

Open the local URL printed by Hugo. To build the same production output as CI:

```sh
hugo --source website --gc --minify --panicOnWarning
python3 scripts/check-website.py
```

Generated output in `website/public/` is ignored by Git.

## Edit

- `website/data/zh.json`: Chinese copy (default homepage).
- `website/data/en.json`: English copy (`/en/`).
- `website/layouts/`: shared Hugo templates and SVG icons.
- `website/assets/css/site.css`: responsive styles.
- `website/assets/js/site.js`: installation-command copy button.
- `website/hugo.toml`: languages, site URL, and existing documentation mounts.

The homepage illustration is an HTML/CSS product concept with labeled sample
tasks, not an app screenshot. The original app icon and multilingual guide are
mounted from `docs/icon.png` and `docs/guide/`, preserving `/guide/` URLs.

## Deployment

In repository **Settings → Pages**, use **GitHub Actions** as the source.
`.github/workflows/pages.yml` builds and deploys when website sources, the
guide, icon, or workflow change on `main`. It can also be run manually from
Actions. Pull requests build and check the site without publishing.

The workflow checks the downloaded Hugo archive against the release checksum.
No additional secrets are required: deployment uses GitHub's `GITHUB_TOKEN`
and OIDC with Pages-specific job permissions. Website-only changes do not
create a new macOS application release.

If changing the deployment URL, update `baseURL` in `website/hugo.toml` and
the `BASE` constant in `scripts/check-website.py` together. The production
build checks all generated local links, assets, and section anchors.

Reference: [Hugo's GitHub Pages deployment guide](https://gohugo.io/host-and-deploy/deploy-to-github-pages/).
